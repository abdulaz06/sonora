# Basis Universal transcoder

`basis_transcoder.mjs` and `basis_transcoder.wasm` are the Basis Universal
transcoder (https://github.com/BinomialLLC/basis_universal), as shipped with
three.js r187 (`examples/jsm/libs/basis`), with one line added to the
JavaScript (`export default BASIS;`) so it loads as an ES module in a worker.
